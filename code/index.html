RISC-V · Assembly language

Every instruction, legible.

Bring structure to RISC-V assembly with syntax highlighting and snippets, from familiar integer instructions to vector and system extensions.

  • Instruction, register and directive highlighting
  • Assembly snippets for everyday editing
  • GCC and LLVM assembler syntax

LLVM IR · Intermediate representation

Find your way through IR.

Read LLVM’s intermediate representation with syntax highlighting, instruction snippets and navigation between functions and basic blocks.

  • Highlight types, instructions and SSA values
  • Snippets for operations such as alloca, br and call
  • Go to Definition within the current file

Ctrl/Cmd-click follows function and block references. Navigation does not resolve SSA values or cross-file declarations.

LLVM MIR · Machine representation

Look inside code generation.

Make machine-level IR easier to inspect, with highlighting for the YAML document and the machine instructions inside it.

  • YAML properties and embedded LLVM IR
  • Machine blocks, instructions and registers
  • Register flags, memory operands and debug attachments

Built for reading MIR files and code-generation tests, with distinct syntax scopes that work with your editor theme.

Assembler syntax, beyond instructions

The grammar recognizes lowercase and uppercase instructions, GCC and LLVM assembler directives, .insn, preprocessors such as #include and #define, and #, // and /* … */ comments.

Selected supported families, not an exhaustive ISA list. See the extension’s Marketplace documentation for the published support list.

VS Code installation guide ↗

  1. Choose your extension

    Use a Marketplace link above, or open the Extensions view in VS Code and search for the full extension ID, such as sunshaoce.RISC-V.

  2. Install in VS Code

    Select Install, or run the extension’s code --install-extension command in a terminal with the VS Code CLI on your PATH.

  3. Open your assembly or IR file

    If the language is not detected, use the language mode selector in the status bar to choose RISC-V, LLVM IR or LLVM MIR. Highlight colors follow your active theme.
